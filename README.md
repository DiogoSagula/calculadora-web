# Calculadora Web - Atividade Prática

Calculadora desenvolvida em ambiente Web adaptada a partir de conceitos de interfaces móveis (Android), utilizando HTML5, CSS3 e JavaScript puro.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação da interface da calculadora e do painel de histórico.
* **CSS3:** Estilização moderna, suporte a temas (claro e escuro) e design responsivo.
* **JavaScript (Vanilla / Puro):** Lógica de cálculo, manipulação de eventos do DOM e suporte a teclas do teclado.

## 💡 Justificativa da Escolha Tecnológica
A escolha por **JavaScript Puro (Vanilla)** deu-se pela facilidade de implementação direta no navegador, permitindo focar no domínio dos fundamentos da manipulação de elementos DOM, gerenciamento de estado e tratamento de eventos lógicos sem a necessidade de compilação ou configuração complexa de frameworks externos.

## 🚀 Como Executar o Projeto
1. Baixe ou clone este repositório em sua máquina.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo **`index.htm`** (ou abra-o diretamente em qualquer navegador web moderno como Chrome, Edge ou Firefox).
